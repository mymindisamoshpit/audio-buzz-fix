# Audio Buzz Fix

## Проблема
Постоянный высокочастотный писк в наушниках на Windows 10/11, который пропадает только при изменении уровня громкости. Проблема возникает из-за статичного положения регулятора громкости в течение длительного времени.

## Решение
Python-утилита, которая в фоновом режиме автоматически изменяет громкость системы на ±1% с интервалом 2 секунды, имитируя действие пользователя. Программа напрямую работает с Windows Core Audio API через библиотеку pycaw.

## Как это работает
1. Программа получает доступ к аудиоустройству через COM-интерфейс IAudioEndpointVolume
2. Каждые 2 секунды громкость увеличивается на 1%, затем уменьшается на 1%
3. Изменения настолько малы (1%), что незаметны на слух, но предотвращают появление писка
4. Громкость ограничена диапазоном 0-100% для предотвращения ошибок

## Установка и запуск
1. Установить Python 3.x
2. Установить зависимости: `pip install pycaw comtypes`
3. Запустить: `audio_buzz_fix.py`
4. Для остановки: Ctrl+C

## Требования
- Windows 10/11
- Python 3.7+
- Библиотеки: pycaw, comtypes
